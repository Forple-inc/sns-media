# sns-media

Public images for Forple's SNS posts. Served by GitHub Pages so Threads can fetch them:
`https://forple-inc.github.io/sns-media/threads/<file>`

Only finished post images are stored here. No code, keys or drafts.

`forple-publisher/` holds the public pages (about, privacy policy, terms) of Forple Publisher, the internal tool that
uploads Forple's own videos to its YouTube channel and TikTok account. Google's YouTube API audit asks for these URLs:
`https://forple-inc.github.io/sns-media/forple-publisher/` (`privacy.html`, `terms.html`).
